# DSEU Help — Academic Companion for DSEU Students

A web platform built for DSEU students to access semester 
papers and notes easily — all in one place.

## Features
- Semester-wise previous year papers
- Notes for all subjects
- Clean and fast UI
- Mobile friendly

## Problem it Solves
DSEU students had no central place to find papers and notes.
This website solves that problem.

## Tech Used
- HTML
- CSS
- JavaScript
